Four minutes after the homework PDF hit ChatGPT, the code compiled and the sample tests went green. Two days later, in office hours, they could not explain a single function — and they were more lost than before they pasted anything. Getting caught is one failure mode. The worse one is shipping code you do not understand, then sitting down to an exam with a blank editor and no model in the room. This is the session workflow that keeps the tool: twenty-five minutes on paper first, ask it to explain the problem not write the solution, write the code yourself, then make it grill you. If you cannot say every line out loud, you do not submit it.
