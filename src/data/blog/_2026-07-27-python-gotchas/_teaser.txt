Put def add_item(item, bucket=[]): on a whiteboard, call it twice, and watch people write two separate lists while Python hands back one shared object. That is not a compiler bug and it is not trivia. Python never gave you boxes that hold values; it gave you names pointing at objects, and almost every famous gotcha — default arguments evaluated at def time, lambdas that all remember the last loop value, class attributes that leak across instances, += that mutates a tuple slot then raises, is that lies about integers — is that model in costume. Learn the arrows, and the quiz stops being a list of party tricks.
